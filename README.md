# ChristmasTreeBNB

This folder contains the ChristmasTreeBNB token showcase.

## Files

- [`contracts/ChristmasTreeBNB.sol`](contracts/ChristmasTreeBNB.sol) — token contract with configurable buy, sell, and transfer taxes, liquidity and gift-fee handling, transaction limits, and owner controls.
- [`config.json`](config.json) — project metadata naming the Solidity entry point, compiler version, and a generated-artifact path.
- [`truffle-config.js`](truffle-config.js) — Truffle configuration stub; it currently exports an empty configuration.
- [`notes.txt`](notes.txt) — empty notes file.
- [`contracts/README.md`](contracts/README.md) — inventory of the project-owned Solidity source in `contracts`.

The generated-artifact path in `config.json` is descriptive metadata; this showcase contains source and text files only.
